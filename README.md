# Superstore-Sales-Analysis-Machine-Learning-Project

# Overview
This project explores retail sales data to extract business insights and build a predictive machine learning model for profit estimation.  It demonstrates skills in data analysis, visualization, and machine learning using Python.

# Objectives
Clean and preprocess real-world sales data. Perform exploratory data analysis (EDA). Identify key business insights. Build a regression model to predict profit. Evaluate feature importance

# Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

# Dataset
Superstore Sales Dataset (Retail transactions including sales, profit, region, category, and discount information)

# Key Analysis
Data Cleaning

Removed duplicates. Handled missing values. Converted date fields. Created new feautures (profit margin, month, year)

Exploratory Data Analysis

Sales trends over time. Profit distribution across regions. Category-wise performance. Sub-category profitability. Correlation between discount and profit

Machine Learning Model

A Random Forest Regressor was used to predict profit based on: Sales, discount and quantity

Model Performance

Evaluated using Mean Absolute Error (MAE). Feature importance analysis performed

# Key Insights
Certain product sub-categories generate negative profit. Discounts strongly affect profitability. West region shows highest profit consistency. Sales and profit are moderately correlated

# Visualizations
Includes: Sales trend line charts. Category bar charts. Heatmaps. Feature importance plots

# Skills Demonstrated
Data cleaning. Exploratory data analysis. Data visualization. Machine learning (regression). Feature engineering
