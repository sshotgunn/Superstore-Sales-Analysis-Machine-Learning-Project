How to Run

* Install any code editor with Python (For example: Anaconda Navigator -> Spyder, Visual Studio Code)
* Download both analysis.py and streamlit.py from the Python Files branch
* Download the superstore csv file from the Data branch
* Put all the files in one folder on your local device
* To see changes in the csv file, uncomment this line at the end of analysis.py: df.to\_csv("Superstore.csv", index=False)
* The following libraries need to be installed in the editor:

  * pandas
  * matplotlib
  * seaborn
  * sklearn
  * streamlit



* To run the streamlit.py file, use this bash command

  * streamlit run streamlit\_app.py
